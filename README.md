# Planets Expanded
![alt text](<Screenshot 2026-09-21 at 8.22.33 PM.png>)
Planets Expanded is a website I made using Three.js where you can explore different planets in 3D.

You can choose a star system, look through the planets in that system, and then open a 3D viewer for each planet.

You go take a peek here: https://194500-cpu.github.io/APOD/

## Features (This is what I made up to now)

- 3D planet viewer using Three.js
- Solar System planets
- TRAPPIST-1 planets
- Proxima Centauri b
- Custom planet textures
- Saturn rings
- Planet information
- OrbitControls so you can move around the planet
- Back button that returns to the correct star system
- nebula background
- Randomly generating constellations on the homepage
- A dedicated page for help
